# Aaalice_Workflow_SDXL v1.5.1

这是 `Aaalice_Workflow v1.5` 的非官方 SDXL 扩展版。

## 快速使用

1. 把包内 `inputs/67b0dddf8124-Aaalice_example.jpg` 安装为 `ComfyUI/input/Aaalice_example.jpg`。
2. 导入 `workflow.json`。
3. 在侧边栏选择 `默认-SDXL-WAI-v16`。
4. 在底模加载器开启 `SDXL模式`，并选择自己的完整 SDXL Checkpoint。

预设默认模型路径是 `SDXL\waiIllustriousSDXL_v160.safetensors`；模型文件不包含在本包中。本机路径不同或使用其他 SDXL 模型时，请在下拉框中重新选择。

原始工作流：https://github.com/Aaalice233/Aaalice-Workflows
